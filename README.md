# 스페인어 기말고사 대비 — 2026학년도 1학년 2학기

국제학교 1학년 2학기 스페인어 기말고사 범위(수업 PPT 422장)를 학습용 인터랙티브 사이트로 정리했습니다.

## 시험 범위

| 단원 | 주제 | 핵심 질문 |
|---|---|---|
| 01 | 인사와 자기소개 | ¿Cómo te llamas? |
| 02 | 출신과 국적 | ¿De dónde eres? |
| 03 | 직업과 일하는 장소 | ¿A qué te dedicas? |
| 04 | 집과 사물의 위치 | ¿Dónde está? |

## 기능

- **핵심 문법** — 단원별 문법 포인트를 접었다 펼치는 카드로 정리, 예문마다 발음 듣기
- **어휘** — 400여 개 어휘를 그룹별로 정리. 검색, "외웠어요" 체크, 모르는 것만 보기
- **동사 활용** — llamarse · ser · hablar · vivir · trabajar · estar · tener 6인칭 표 + 빈칸 채우기 연습
- **대화** — 수업 대화문 전체 재생(문장 따라 강조), 한국어 가리기
- **플래시카드** — 단어/문장 카드, 스→한·한→스 전환, 키보드 조작
- **집중 연습** — 받아쓰기, 짝 맞추기 게임, 단원별 특별 연습(색깔·숫자·수도 퀴즈·고양이 위치·ser/estar/hay/tener 선택)
- **퀴즈** — 단원별 총 121문제(선택형·주관식), 즉시 해설, 틀린 문제만 다시 풀기
- **종합 모의고사** — 범위·문항 수·타이머 선택, 최고 점수 기록
- **시험 직전 한 장 정리** — 인쇄/PDF 저장용 요약

발음은 브라우저 음성 합성(Web Speech API)으로 스페인어 원어민 목소리를 우선 선택합니다.
학습 기록(외운 단어, 퀴즈 점수, 학습 계획 체크)은 브라우저에 저장됩니다.
